## ✨ Features of the Portfolio Web App

1. **Academic & Degree Spotlight**: In-depth showcase of Information Systems degree from Haramaya University, coursework breakdown, and capstone project.
2. **Interactive Projects Gallery**: Filterable showcase of mobile applications (Flutter), enterprise information systems, web apps, and API services with architectural breakdowns.
3. **Live GitHub Synchronization**: Real-time integration with `@nafiijun` GitHub API displaying public repositories, languages, and profile telemetry.
4. **Interactive CLI Terminal**: Integrated developer console emulator with custom commands (`help`, `about`, `skills`, `education`, `projects`, `contact`).
5. **Printable / Exportable CV**: Formatted interactive resume with one-click print/PDF export and plain-text copy.
6. **Direct Inquiry Channel**: Multi-subject contact form with pre-filled mail generation and contact shortcuts.

## 🚀 Local Development Setup

```bash
# Clone the repository
git clone https://github.com/nafiijun/matiyos-portfolio.git

# Navigate into project directory
cd matiyos-portfolio

# Install dependencies
npm install

# Start local development server
npm run dev
```

Build for production:
```bash
npm run build
```
